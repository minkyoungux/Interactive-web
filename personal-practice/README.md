# 물 · A DROP OF WATER

손끝에 반응하며 출렁이는 투명한 물방울 실습입니다. 반사광, 굴절과 얕은 청색 흡수로 물의 재질을 표현합니다.

## 실행

상위 `interactive` 폴더에서 `npm run dev`를 실행하고 표시된 주소의 `/personal-practice/`를 엽니다.

## 조작

- 마우스 / 손가락으로 건드리기: 표면에 작은 잔물결이 생깁니다.
- 누르기: 닿은 부분이 움푹 들어갑니다.
- 놓기: 물방울이 출렁이며 작은 방울이 튀었다 돌아옵니다.
- 최대 다섯 접점, 일시정지 / 재생, 다시 시작
- 캔버스에 키보드 포커스: 방향키로 이동, 스페이스로 누르기 / 놓기
- 기기의 동작 줄이기 설정에서는 정지 상태로 시작합니다.

## 수정할 곳

- `index.html`, `style.css`: 화면과 버튼
- `main.js` → `MeshPhysicalMaterial`: 투과, 굴절률, 물의 색상
- `softbox()`: 표면에 비치는 조명
- `splash()`: 작은 물방울의 분리와 복귀
- `water-surface.js`: 표면의 복원력, 감쇠, 누르는 힘과 잔물결

구형 표면의 각 꼭짓점이 독립적인 변위와 속도를 갖는 시각적 근사 모델입니다. 유체 역학의 정확한 시뮬레이션은 아닙니다. 외부 배경 이미지 없이 Three.js로 그리며 WebGL 지원이 필요합니다.

검사: 상위 폴더에서 `node --test personal-practice/water-surface.test.js`.
