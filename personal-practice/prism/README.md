# PRISM · 빛의 막

13개의 넓고 얇은 반투명 리본을 방사형으로 겹칩니다. 리본은 각각 72×38개의 면으로 나뉘며 폭 방향의 접힘, 굽은 끝과 미세한 결을 갖습니다. 접힌 가장자리와 끝부분에 색분산과 블룸을 더합니다.

상위 폴더에서 `npm run dev` 후 `/personal-practice/prism/` 접속.

쓸면 접촉한 리본이 휘고, 누르면 응축되며 놓으면 천천히 풀립니다. 리본 길이 방향의 탄성 연결이 움직임을 전달합니다. 방향키와 스페이스, 일시정지, 초기화를 지원합니다.

`main.js`의 `shape()`는 실제 리본 면과 탄성 운동을 갱신합니다. 셰이더는 면의 반투명 빛, 결, 가장자리 색상을 만듭니다. 배경 이미지를 사용하지 않습니다.
