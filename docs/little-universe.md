# 입을 벌리면 작은 우주 / LITTLE UNIVERSE

`npm run dev` 후 `/little-universe.html` 또는 홈의 **17 · Little Universe**에서 열기.

카메라를 켜고 얼굴을 비춘 뒤 입을 벌려보세요. 얼굴을 덮던 미세 입자들이 약 4.5초에 걸쳐 떠올라 곡선을 그리며 나선형 은하에 모입니다. 이동하는 입자에 짧은 빛 꼬리가 이어지고, 거의 자리를 잡으면 일곱 개의 가상 별자리 선이 드러납니다. 눈을 뜬 채 이동 과정을 볼 수 있습니다. 입을 오래 벌리고 있으면 우주가 넓어집니다.

입을 닫으면 기다림 없이 현재 이동 지점부터 얼굴로 되돌아옵니다. 완전히 펼쳐진 은하가 얼굴로 돌아오는 시간은 약 3.4초입니다. 이전의 눈 감기 동작과 6초 감상 대기는 제거했습니다. 화면에 입을 벌린 시간과 입자 이동 진행률을 표시합니다.

카메라 없이 **누르고 입 벌리기** 버튼을 누르고 있거나, 캔버스 또는 미리보기 버튼에 포커스하고 스페이스바를 길게 누르면 체험할 수 있습니다. 놓으면 다시 모입니다. **다시 얼굴로** 또는 Escape는 전환을 초기화합니다. 계속 입을 벌리고 있다면 다시 감지가 시작되므로 입을 닫아주세요.

원형 촬영 버튼을 길게 누르면 녹화를 시작하고 다시 누르면 저장합니다. 짧게 누르면 사진이 저장됩니다.

## 구현

기존 Prism Face의 canonical 얼굴 데이터와 로컬 MediaPipe 모델을 재사용합니다. Face Landmarker는 별도 Worker에서 `jawOpen` blendshape 점수와 입술 사이 거리로 입 벌림을 판정합니다. 입술 거리는 입 너비와 영상 종횡비로 보정합니다. 약 0.16초 동안 입을 벌린 상태를 확인하고, 닫힘에는 별도의 낮은 기준을 적용해 점수 흔들림을 처리합니다. 얼굴을 놓치거나 탭을 숨기면 입 벌림 시간을 초기화합니다.

데스크톱 120,000개, 모바일 60,000개 입자를 사용하며, 막이나 얼굴 표면 Mesh는 그리지 않습니다. 은하 이미지를 띄우지 않고 같은 입자의 좌표를 매 프레임 이동시킵니다. 얼굴과 은하 좌표 사이에 상승 및 회전 제어점을 둔 3차 Bezier 경로를 사용하고, 입자마다 출발과 도착 시점을 다르게 배치합니다. 각 입자의 얼굴 UV와 seed로 계산한 무지갯빛을 은하에서도 그대로 사용하며, 이동 시작부터 복귀가 끝날 때까지 색상 위상을 고정합니다. 비슷한 얼굴 색의 입자를 같은 나선 팔에 배치해 색이 무작위로 섞여 하얗게 보이는 것을 줄였습니다. 이동 중에는 움직임 꼬리를 표시하고 꼬리와 별자리 선도 원래 입자 색을 사용합니다. 별자리와 꼬리에도 같은 경로를 사용합니다.

시간에 따른 우주 팽창은 최대 1.9배로 부드럽게 수렴합니다. 카메라 영상은 우주 전환 중 어두워져 사라지고 얼굴로 복귀할 때 다시 보입니다. 움직임 줄이기 설정에서는 공전과 반짝임을 멈추고 입자의 상승 거리를 줄입니다.

영상은 서버에 전송하지 않습니다. 카메라 끄기와 홈의 다른 탭으로 이동할 때 영상 트랙, Worker, WebGL 자원을 종료합니다. 숨겨진 탭에서는 렌더링과 추론을 중단하고 카메라 트랙을 비활성화합니다.
