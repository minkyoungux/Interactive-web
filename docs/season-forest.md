# 계절의 숲 · A Little World

`/season-forest.html` 또는 실험 허브의 `/#season-forest`에서 실행합니다.

민트빛 바다 위에 작은 마을과 숲이 자리한 장난감 같은 지구입니다. 크림색 종이와 세이지색 UI, 둥근 수목과 파스텔 지붕으로 느긋한 생활 시뮬레이션의 분위기를 표현합니다. 지형은 실제 대륙을 복제하지 않은 상상의 군도이며, 모든 오브젝트는 Three.js로 제작한 3D 지오메트리입니다.

16개 섬에 온대 숲, 고산 침엽수림, 꽃 초원, 열대 해안, 사막, 습지를 배치했습니다. 숲 내부까지 수목을 채우되 호수·마을·오솔길은 비워 두고, 꽃 무리·버섯·풀·갈대·수련·토끼를 작은 디테일로 더했습니다. 적도 부근 열대 수목과 사막은 고유 색을 유지하고, 온대 숲과 초원은 반구별 계절을 따릅니다. 고산 정상에는 만년설을 표현합니다.

반복 오브젝트는 지오메트리·재질별 `InstancedMesh`로 묶습니다. 계절 눈은 반구별로 별도 묶어 월 변경 시에도 독립적으로 표시합니다.

바다에는 상어·고래·바다거북·물고기 떼가 해안과 얕은 물을 피하는 폐곡선 경로를 따라 헤엄칩니다. 생물별 꼬리·지느러미 동작, 고래의 물뿜기, 수면의 물결을 표현합니다. 경로 생성 시 몸 크기까지 포함해 바다 여부를 검사합니다. 동작 줄이기 설정에서는 생물은 보이되 수영 애니메이션을 멈춥니다.

- 드래그 / 한 손가락: 지구 회전
- 휠 / 두 손가락 핀치 / +·− 버튼: 확대·축소
- 방향키 / +·− / Home: 키보드 탐색과 시점 초기화
- 월 선택: 북반구·남반구의 잔디와 수목 색 변경, 겨울 지붕·침엽수의 눈 표시
- 입주하기: 이미지 선택 → 5초 자동 촬영 → 미니어처 미리보기 → 주민 추가와 산책. [처리 방식과 제한](season-forest-settlement.md)
- 자동 회전, 구름, 적도 표시 전환
- 마우스로 휘젓기: 주변 나무가 휘청인 뒤 복원되고, 바다 생물은 커서 반대쪽으로 피한 뒤 경로로 복귀합니다. 클릭 없이도 작동하고 회전 드래그와 함께 사용할 수 있습니다. 한 손가락에도 반응하며 두 손가락 핀치 중에는 반응을 억제합니다.

북반구는 3–5월 봄, 6–8월 여름, 9–11월 가을, 12–2월 겨울로 표현하고 남반구에는 반대 계절을 적용합니다. 지역별 기후 차이를 단순화한 온대 계절 컨셉입니다. 최초 월은 사용자의 현재 날짜를 사용합니다.

자동 회전은 기본으로 꺼져 있습니다. 동작 줄이기 환경에서는 구름 이동과 색 전환 애니메이션도 멈춥니다. 페이지 전환 시 GPU 리소스와 이벤트 리스너를 해제합니다.

검증: `npm run build`, `node tests/season-forest-browser.cjs` (실행 중인 Vite 서버 및 Chrome 필요). 다른 서버 주소를 첫 번째 인자로 전달할 수 있습니다.
# 심해 배경

`season-forest-deep-fauna.ts`는 지구 바깥에 지구 지름과 비슷한 거대 상어와 더 긴 고래, 해파리 7마리, 발광 물고기 24마리를 만듭니다. 상어·고래는 서로 반대 방향의 입체 경로를 유영하고 각각 좌우/상하 꼬리 운동을 합니다. 지구 내부의 기존 바다 생물과 별개의 장면이며 주민의 이동·선택 로직을 바꾸지 않습니다. reduced-motion 및 GPU 리소스 해제를 지원합니다.

`season-forest-deep-sea.ts/.css`가 지구 바깥의 짙은 청록·남색 심해, 수면에서 내려오는 느린 빛줄기, 상승하는 기포와 부유 입자를 구성합니다. 지구·주민·섬 좌표와 상호작용은 유지하고 조명과 HUD 색상만 수중 분위기에 맞췄습니다. 배경은 포인터를 가로채지 않으며 reduced-motion에서는 배경 움직임도 정지합니다. 화면 종료 시 배경 DOM과 GPU 리소스를 해제합니다.
