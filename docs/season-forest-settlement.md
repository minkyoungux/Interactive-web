# 주민 입주

## 현재 동물 주민 방식

입주 창에서 토끼·고양이·곰·강아지·다람쥐·사슴 몸체를 선택합니다. 카메라 사진의 윤곽은 몸체에 사용하지 않습니다. 업로드한 동물 참고 이미지는 기본 색상에만 사용하고, 촬영된 실제 사람 사진을 HumanSeg와 신체 랜드마크로 잘라 동물형 3D 메시의 얼굴·몸통·팔다리 표면에 입힙니다. 뒷면과 보이지 않은 신체 부위는 기본 재질을 유지합니다. 외부 생성형 모델이나 원본 캐릭터의 정밀 복제가 아닌 절차적 미니어처입니다.

동물 8명과 외계 탐사대 4명이 최초 한 번 입주합니다. 외계인은 외눈·긴 머리·버섯 모자·세 눈/세 다리 등 네 외형과 잠자리채를 갖습니다. 성격 6종에 따라 인사·교류·사용자 대화가 달라집니다. 외계인은 같은 섬의 동물을 적극적으로 찾고 일반 산책의 5배 속도로 추격합니다. 동물은 지그재그로 도망갑니다. `탐색 → 추격 → 잠자리채 포획 → 우주선 귀환 → 생태 관찰 → 안전하게 풀어주기 → 이륙/재탐사` 순서로 진행하며 동물 삭제나 피해는 없습니다. 카메라로 추적 중이어도 임무는 계속됩니다. 회의·드래그·방출은 임무를 취소하고 포획된 동물을 원상 복구합니다. 첫 네 섬에 우주선 착륙 공간을 비웠습니다. 기본 주민도 이동·이름 변경·회의·방출·저장 대상이며 방출 후 새로고침해도 자동 재생성하지 않습니다.

대화 UI는 크림색의 넓고 둥근 말풍선, 민트색 이름표, 노란 아래 표시를 사용합니다. 추적 시 중앙에 최신 주민 대사 하나를 크게 보여주며 과거 메시지는 `이전 대화`에 접어 둡니다. 머리 위 대사도 같은 디자인을 사용합니다.

화면 가림을 줄이기 위해 현재 대화는 **3D 뷰포트 아래 별도 공간**에 표시합니다. 대화/꾸미기 도구를 펼쳐도 ResizeObserver가 장면 높이를 조정해 겹치지 않습니다. 월·계절·구름·자동 회전은 `세계 설정`에 모았고 이름표는 기본 숨김입니다. 주변 대사는 하단에 한 개씩만 표시하며 `UI 숨기기 / UI 보기`로 관찰 모드를 전환합니다. `tests/season-forest-ui-smoke.cjs`는 데스크톱에서 대화/장면 경계 비중첩, 도구 확장, UI 토글, 이동된 달력 동작만 확인합니다.

기존 윤곽형 주민 데이터는 삭제하지 않고 보존합니다. 이전 합성 사진에서는 원본 촬영 부위를 온전히 복원할 수 없으므로 새 동물 몸체에 내 사진을 정확히 적용하려면 다시 촬영해 입주해야 합니다.

하단 `입주하기` → 좌측 카메라 / 우측 이미지 드롭존 → 이미지 선택 후 5초 자동 촬영 → 사람/대상 인식 → 중앙 3D 미리보기 → 축소 입주 → 섬 안에서 임의 목적지 산책.

사진은 서버에 업로드하지 않습니다. 모든 모델은 같은 출처의 정적 파일로 제공하고, 인식은 Web Worker에서 처리합니다. 주민의 이름·위치·외형·편집한 텍스처·최근 대화는 IndexedDB에 저장하며 페이지를 닫았다 다시 열어도 복원합니다. 같은 PC의 **같은 브라우저 프로필·같은 사이트 주소(프로토콜/호스트/포트)** 기준입니다. 시크릿 모드 종료, 사이트 데이터 삭제, 브라우저의 저장 공간 정리 시에는 사라질 수 있습니다. 저장 실패는 화면에 표시합니다. 저장된 사진은 원본 카메라 프레임이 아니라 주민에 사용한 합성 텍스처입니다.

## 주민과 생활하기

- 생성 창에서 이름 지정, 주민 클릭/이름표/주민 목록으로 추적 시점과 대화창 열기. `추적 종료`, Escape 또는 빈 지도 클릭으로 복귀합니다.
- 대화는 외부 AI 호출이 없는 로컬 대사/키워드 응답입니다. 자유 텍스트 입력, 인사·산책 질문, 이름 변경을 지원합니다.
- 주민이나 이름표를 누른 채 드래그해 섬의 땅 위로 이동합니다. 바다나 호수 등 유효하지 않은 위치에 놓으면 원래 자리로 돌아갑니다. 터치 포인터도 지원합니다.
- `구덩이 찾기`로 방출 위치를 봅니다. 주민을 구덩이에 드래그해 놓으면 내려가는 연출 후 방출되고 저장소에서도 제거됩니다. 10초간 `되돌리기`가 가능합니다. 페이지를 닫으면 이 되돌리기 기회는 종료됩니다.
- `주민 회의`는 모든 주민을 홈 섬의 공터로 이동시킵니다. 다른 섬의 주민은 짧은 이동 연출로 모이고, `회의 마치기`로 산책을 재개합니다.
- 대화창의 `텍스처 수정`: 문질러 섞기, 색칠하기, 편집 전 모습으로 복원하는 브러시. 크기·색상 선택, 12단계 되돌리기, 취소·수정 저장을 지원합니다. 텍스처만 바꾸며 외형 윤곽은 바꾸지 않습니다.

## 인식과 미니어처 스타일

- HumanSeg: 기존 selfie segmenter의 `selfie` 신뢰도 마스크. 신뢰도 0.72보다 높은 사람 픽셀만 실제 사진 텍스처로 사용하고, 나머지 픽셀은 RGB와 알파 모두 0으로 만듭니다. 경계는 마스크 안쪽으로 부드럽게 처리합니다.
- Body Landmark: PoseLandmarker Lite의 33개 신체 좌표로 얼굴·몸통·좌우 팔·다리 사진을 분리합니다. 얼굴은 비율을 보존해 머리 앞면에, 몸통은 어깨/골반 좌표를 이용해 옷에, 팔다리는 관절을 따라 편 사진을 해당 부위에 매핑합니다.
- 대상 추출: 투명 PNG는 알파를 유지합니다. 불투명 이미지는 MagicTouch, 사람으로 검출된 레퍼런스는 HumanSeg 전경 마스크를 사용합니다. 화면 중앙과 대비를 바탕으로 대상을 선택하므로 여러 대상이 있는 이미지는 잘못 선택될 수 있습니다.
- 새 주민은 선택한 동물형 3D 몸체를 사용합니다. 업로드 이미지와 촬영된 사람의 실루엣을 몸체로 사용하지 않습니다.
- 사진은 색상 참고용이 아니라 **실제 외형 텍스처**입니다. HumanSeg 내부의 부위별 실제 픽셀을 곡면 표면에 합성합니다. 사진이 없는 부분은 기본 동물 재질이며 단일 사진으로 보이지 않는 부위까지 복원하지 않습니다.

## 모델링의 범위

`season-forest-villager.ts`와 `season-forest-resident-style.ts`가 동물/외계인 입체 모델을 만듭니다. 기존 `season-forest-resident-shape.ts`의 2.5D 윤곽 재구성은 이전 저장 데이터의 복원용으로만 유지합니다.

평소 산책은 섬의 땅에서 임의의 목적지·정지 시간·방향을 선택합니다. 해안·연못·방출 구덩이는 피하지만 모든 나무·집을 피하는 경로 탐색이나 바다를 건너는 내비게이션은 아닙니다.

## 생명주기

이미지 교체는 카운트를 초기화합니다. 창 닫기, 탭 숨김, 카메라 중단은 촬영을 취소합니다. 캡처 직후 카메라를 끄며, 늦게 도착한 권한 응답도 트랙을 종료합니다. 실패 시 재촬영을 제공하고 처리 결과가 취소된 창으로 유입되지 않도록 세대 토큰을 사용합니다. 퇴장/페이지 전환 시 워커와 GPU 리소스를 해제합니다.

## 검증

`node tests/season-forest-expedition-smoke.cjs`: 데스크톱 한 환경에서 추적 중 달리기·잠자리채 휘두르기·포획·실제 이동으로 우주선 귀환·관찰·해제·이륙과 회의 중단을 확인합니다. 카메라나 인물 샘플 없이 실제 프레임 업데이트를 진행하는 변경 범위 전용 검사입니다.

`node tests/season-forest-resident-life-browser.cjs`: 저장 데이터로 주민 복원, 이름 변경·대화, 추적 카메라, 브러시/되돌리기/취소/저장, 실제 포인터 드래그, 회의 집합, 구덩이 방출·취소·재방출, 리로드 후 외형/이름/대화 복원과 삭제 유지, 모바일 화면, 리소스 해제를 검증합니다.

`tests/season-forest-settlement-browser.cjs`는 이전 윤곽형 입주의 통합 테스트입니다. 기본 샘플 인물 사진 사용을 중단했으며 `RESIDENT_TEST_PHOTO`가 없으면 실행하지 않습니다. 새 주민 수/동물 모델 구조에 맞춘 전체 회귀 검증은 별도 요청 시 진행합니다.

`node tests/season-forest-resident-photo-browser.cjs`: 합성 마스크로 배경 픽셀 배제, 사진 디테일 유지, 얼굴·몸통·팔다리 매핑, 관절 누락 처리, 물건형 사진 적용과 GPU 텍스처 해제를 검증합니다.

`node tests/season-forest-resident-shape-browser.cjs`: 토끼·비대칭 꼬리가 있는 고양이·구멍이 있는 물건 입력으로 앞면 실루엣 IoU > 0.95, 서로 다른 메시, 실제 사진 합성, 리소스 해제를 검증합니다. 이 수치는 분리된 마스크 대비 일치도이며 원본 사진의 전경 분할 정확도나 완전한 3D 복원 정확도가 아닙니다.

새 작업에서는 스톡 인물 사진을 내려받거나 가짜 카메라 사진으로 사용하지 않습니다.
